# AutoRental

Application Web de location de véhicules en libre-service.

## Technologies

- Backend : Django
- Frontend : React
- Base de données : MySQL
- API : REST
- Authentification : JWT
- Cloud : Microsoft Azure

## Structure du projet

- Documents_Reference : documents officiels du TFE
- Working_Documents : documents de travail
- Backend : code Django
- Frontend : code React
- Database : scripts SQL
- Azure : déploiement
- Docs_Developpement : documentation technique
